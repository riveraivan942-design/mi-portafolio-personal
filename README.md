# Mi Portafolio Personal

Sitio web personal con información profesional y formulario de contacto funcional.

## 📋 Descripción

Proyecto desarrollado para mostrar información personal, habilidades, proyectos y un sistema de contacto que guarda los mensajes en una base de datos MySQL.

### Características

- ✅ Diseño responsive con Bootstrap 5
- ✅ Página principal con biografía, hobbies y proyectos
- ✅ Formulario de contacto con validación HTML5 y PHP
- ✅ Almacenamiento de mensajes en base de datos
- ✅ Mensajes de confirmación con sesiones
- ✅ Protección contra inyección SQL (PDO)
- ✅ Contador de caracteres en tiempo real

## 🛠️ Tecnologías

- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
- **Backend**: PHP 7.4+
- **Base de datos**: MySQL
- **Iconos**: Font Awesome 6
